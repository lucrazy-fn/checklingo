Português

O CheckLingo é uma extensão independente criada por lucrazy-fn para personalizar e melhorar as lições e partidas de xadrez do Duolingo.

Dados processados

A extensão lê, apenas no navegador, o conteúdo necessário das páginas do Duolingo para identificar textos e o tabuleiro de xadrez. Isso permite substituir palavras, destacar jogadas, mostrar coordenadas, desenhar setas e montar o histórico da partida.

Preferências armazenadas

Idioma, tema, palavras personalizadas, cores e opções dos recursos são salvos com storage.local. Esses dados permanecem no navegador e podem ser removidos ao apagar os dados ou desinstalar a extensão.

Transmissão e compartilhamento

O CheckLingo não envia dados para servidores do desenvolvedor, não vende informações, não usa anúncios, não cria perfis e não compartilha dados com terceiros. A extensão não exige conta.

Permissões

A permissão de armazenamento salva preferências localmente. O acesso a duolingo.com é usado somente para executar os recursos descritos nas páginas de xadrez.

Uso limitado

O uso de informações pelo CheckLingo segue a Política de Dados do Usuário da Chrome Web Store, incluindo os requisitos de Uso Limitado.

Contato

Dúvidas podem ser enviadas pelo GitHub Issues do CheckLingo.

English

CheckLingo is an independent extension created by lucrazy-fn to customize and improve Duolingo Chess lessons and matches.

Data processed

The extension locally reads the page content required to identify chess text and the board on Duolingo. This enables word replacement, move highlights, coordinates, planning arrows and move history.

Stored preferences

Language, theme, custom words, colors and feature settings are saved with storage.local. This information remains in the browser and can be removed by clearing extension data or uninstalling CheckLingo.

Transmission and sharing

CheckLingo does not send data to developer servers, sell information, display ads, build profiles or share data with third parties. No account is required.

Permissions

The storage permission saves preferences locally. Access to duolingo.com is used only to provide the described features on chess pages.

Limited Use

CheckLingo's use of information complies with the Chrome Web Store User Data Policy, including the Limited Use requirements.

Contact

Questions can be submitted through CheckLingo GitHub Issues.
